Modern React gives us powerful primitives, but many applications still become difficult to reason about as they grow. State spreads across components, effects become overloaded, and subtle bugs start creeping in.

This workshop introduces a practical mental model for writing more predictable React applications. Through real-world examples, we'll explore common anti-patterns around components, state, effects, and logic — and replace them with simpler, more maintainable approaches using React’s built-in primitives such as hooks, Context, derived state, and more.

The goal is to help you write React code that stays reliable, scalable, and easy to reason about.
