jPrefetch is a small jQuery plugin that adds a more dynamic interface for HTML5 link prefetching. It can prefetch a supplied URL or the first link marked with <code>data-prefetch="true"</code>, choosing the browser-specific prefetch or prerender behavior where supported. For more context, see the article <a href="/blog/markup/html5-prefetching/" target="_blank" rel="noopener noreferrer"><strong>HTML5 prefetching</strong></a>.
